# AI QA System

A hands-on repository focused on evaluating and testing AI-powered systems, including retrieval-augmented generation (RAG) applications, large language models (LLMs), and AI agents.

This project contains a structured set of sections covering the full lifecycle of AI QA and evaluation workflows, from introductory concepts to advanced testing strategies.

## Overview

The repo is organized into a sequence of learning and experimentation modules:

- Section1_Introduction
- Section2_UsingLocalLLMForActualDataCreation
- Section3_TestingRAGApplication
- Section4_TestingRAGAdvanced
- Section5_AIAgentTesting
- Section6_TestingWithRAGAs
- Section7_TestingRAGWithRAGAs
- Section8_TestingLLMs
- Section9_TestingLLMsAdvanced
- Section10_ComponentTestingRAGApplication
- Section11_AIAgentComponentTesting

## What this repository covers

- Testing and validating RAG workflows
- Evaluating LLM responses and quality
- AI agent testing and component validation
- Local LLM-based data generation workflows
- Practical examples and experiments for AI QA systems

## Project files

- `test.py` — a simple example using `deepeval` to measure answer relevance for an LLM test case.
- `.gitignore` — repository ignore rules.

## Example usage

Run the sample evaluation script:

```bash
python test.py
```
